## 一、先弄清类型：你的号属于哪一种？

- **功能受限**：能登录，但发布、评论、直播被灰掉，或提示暂时无法使用。
- **身份 / 手机验证**：要求邮箱、短信或人脸视频验证。
- **违规停用**：登录后直接进入停用页，需要走官方申诉。
- **关联风控**：同一手机、同一网络下多个号一起异常。
- **版权 / 冒充投诉**：提示涉及版权或身份冒充，材料要对应证明。
